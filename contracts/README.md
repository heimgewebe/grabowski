# Contracts

Repository-owned machine-readable bindings and compatibility contracts.

`chronik-coding-memory-runtime.binding.v1.json` pins the producer identity for the vendored Chronik coding-memory runtime contract in `chronik-coding-memory-runtime.v1.json`. The corresponding validation logic lives in `tools/validate_chronik_coding_memory_runtime.py` and is part of the repository and deploy gates.
